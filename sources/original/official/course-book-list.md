## Usage Rules for the Project

1. The human owner's course PPTs remain the **primary source**.
2. Teacher notes are used as course-support material.
3. Textbooks and reference books are **secondary sources**.
4. Secondary sources may be used only when the PPTs or teacher notes are unclear, incomplete, or require additional explanation.
5. Any content derived from books must be marked with `origin: secondary`.
